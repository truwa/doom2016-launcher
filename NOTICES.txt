Wine
  LGPL-2.1-or-later
  Downloaded on first launch from the latest WineHQ macOS build published by Gcenx:
  https://github.com/Gcenx/macOS_Wine_builds/releases/latest

Microsoft Visual C++ 2015–2022
  Downloaded on first launch from Microsoft and installed into this app's Wine prefix.
  Wine's own C++ runtime crashes DOOM (2016).
  https://aka.ms/vs/17/release/vc_redist.x64.exe

KosmicKrisp
  Mesa, MIT
  This app includes the x86_64 compat build v0.1.0 from
  https://github.com/truwa/kosmickrisp-compat/releases/tag/v0.1.0
  It advertises depthBounds and fillModeNonSolid so DOOM (2016) can create a Vulkan device.
  https://docs.mesa3d.org/drivers/kosmickrisp.html

gogdl
  GPL-3.0
  Downloaded on first use from Heroic Games Launcher's gogdl v1.3.1.
  It signs in to the GOG account that owns the game and downloads that copy.
  https://github.com/Heroic-Games-Launcher/heroic-gogdl
